# UEncoder - Encoding & Hashing Toolbox

> 浏览器本地运行的编码 / 哈希 / 格式化工具集

Universal encoder toolbox - browser-based encoding, hashing, crypto and formatting tools that run 100% locally

## Features

- Base64, URL and HTML entity encoding/decoding
- MD5, SHA-1, SHA-256 and SHA-512 hash calculators
- JSON formatting, validation and minification
- All processing happens locally in the browser
- Works offline once the page is loaded

## Tech Stack

`Encoding` `Hashing` `JSON` `Browser-based` `Privacy`
